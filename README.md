# NetCheck

Приложение для Android, которое проверяет доступность 20 сетевых ресурсов из двух
групп — 10 доступных в России и 10 ограниченных — и по результатам показывает,
работает ли маршрутизация.

**[Скачать последнюю версию →](../../releases/latest)**

---

## Зачем

Проверить, «работает ли обход» и «не сломался ли маршрутизатор», обычными средствами
неудобно: браузер либо открывает страницу, либо нет, и не говорит почему. NetCheck
показывает не факт, а **диагноз** — на какой ступени соединение ломается и как именно.

## Как устроена проверка

Каждый ресурс проходит четыре ступени **по одному соединению**: TCP-сокет открывается
один раз, поверх него идёт TLS, поверх него — HTTP-запрос.

| Ступень | Что делается | Признак отказа |
|---------|--------------|----------------|
| 1. DNS | Разрешение имени | Имя не разрешилось — проблема в DNS |
| 2. TCP | Соединение на порт **443** | Молчание — дроп пакетов; `RST` — блокировка по IP |
| 3. TLS | Рукопожатие с проверкой сертификата | `RST` сразу после ClientHello — фильтрация по SNI; подмена сертификата — вмешательство провайдера |
| 4. HTTP | GET-запрос | Ответ получен, но не тот — отказ сервиса |

Отдельно проверяется сертификат: **проверки никогда не отключаются**, в том числе в
отладочных сборках. Иначе страницу-заглушку провайдера было бы не отличить от
настоящего ресурса.

Доступность проверяется по HTTPS и только по порту 443. Порт 80 не проверяется
намеренно: открытый 80 у заблокированного ресурса дал бы ложный вывод «доступен».

Повтор делается ровно один раз: одиночная потеря пакета в мобильной сети — норма и
не должна давать «недоступен». Успех со второй попытки помечается отдельно —
**нестабильно**.

## Требования

- Android 8.0 (API 26) и новее
- Разрешения: `INTERNET`, `ACCESS_NETWORK_STATE`. Больше ничего — в частности,
  SSID Wi-Fi не читается, поэтому доступ к геолокации не запрашивается.

## Установка

Приложение распространяется сайдлоадом, без Google Play.

1. Откройте **[последний релиз](../../releases/latest)** и скачайте файл
   `NetCheck-<версия>.apk`.
2. Разрешите установку из неизвестных источников для приложения, из которого
   открываете APK (браузер или файловый менеджер).
3. Установите APK.
4. При желании сверьте контрольную сумму — файл `SHA256SUMS` лежит в том же релизе:

   ```bash
   shasum -a 256 -c SHA256SUMS
   ```

Android при установке обновления проверяет подпись: она не меняется между версиями,
поэтому обновления ставятся поверх без удаления приложения.

## Приватность

Приложение не собирает и не передаёт никаких данных о вас, вашем устройстве и
результатах проверок. Телеметрии, аналитики, рекламы и crash-репортинга нет.

Сетевые обращения ограничены двумя контурами, и они независимы:

- **Проверка сети** — запросы к тем 20 ресурсам, которые вы проверяете. Это и есть
  работа приложения.
- **Проверка обновлений** (появится в следующей версии) — обращения только к
  `api.github.com` и `github.com` за сведениями о новой версии. Идентификаторов,
  cookies и модели устройства в запросах нет; `User-Agent` содержит только название
  и версию приложения. Результаты проверок сети в запросы обновления не попадают.
  Проверку обновлений можно отключить.

В текущей версии проверка обновлений ещё не встроена: приложение обращается только
к проверяемым ресурсам.

## Чего приложение не делает

- **Не обходит блокировки и не управляет роутером.** Это измерительный прибор, а не
  инструмент обхода. Он показывает, что происходит с соединением, и не более.
- Не заменяет VPN, не настраивает прокси, не меняет сетевые параметры системы.
- Не оценивает скорость и не определяет пригодность сервиса: ресурс может быть
  доступен, но непригоден (например, видео в низком качестве). Измерение скорости —
  задача будущих версий.
